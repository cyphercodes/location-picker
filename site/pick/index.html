Privacy: this page has no server, no storage and no analytics. The location exists only on this page, in what you copy or share, and at the address it is sent to. Map tiles come from OpenStreetMap and search from Photon (komoot), which see your requests like any map site.

For developers and AI agents: link parameters
Parameter Meaning
lat, lng Start with the pin here (decimal degrees).
zoom Start zoom, 1 to 19.
q Start at the first search result for this text.
lang Language for search results, for example de.
redirect An https:// address. After a click on the send button, the browser goes there with lat, lng and, when known, address added to the query.
return=postmessage + origin Posts { type: 'location-picker:pick', lat, lng, address } to the opener or parent window, only to that exact origin (required).

Example: https://cyphercodes.github.io/location-picker/pick/?q=Eiffel+Tower&redirect=https://example.com/done. For heavy use, host this page yourself: it is a static folder in the MIT-licensed location-picker repository.
