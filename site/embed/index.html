Platform notes

Short and honest: what works, and what to choose in the generator.

Plain HTML forms

Tick “Include a complete form” and set the action. Formspree and Basin accept any field names. Netlify Forms registers fields from your HTML at deploy time, so choose Hidden inputs and add data-netlify="true" and a name to the form.

WordPress

Add a Custom HTML block and paste. Script tags there need the unfiltered_html capability (administrators on a self-hosted site). Form plugins keep only the fields they define: add hidden fields named lat and lng in the plugin (Contact Form 7: [hidden lat]), choose Hidden inputs and tick “My form already has these fields”.

Webflow

Put a Code Embed element inside your Form Block and paste. Webflow’s form handler only collects real inputs, so choose Hidden inputs. Custom code needs a Webflow plan that allows it.

Squarespace

The built-in Form Block cannot take extra fields. Add a Code Block with “Include a complete form” posting to Formspree or Basin. JavaScript in Code Blocks needs a plan that allows it.

Shopify

Add a Custom Liquid block on the product page and choose Hidden inputs named like properties[Delivery location]: the pin is saved with the order line. The inputs must sit inside the product form or carry its form="…" id (theme-specific). Checkout does not run custom scripts.

Where it cannot work

Google Forms and Microsoft Forms have no custom fields or scripts. Wix runs HTML embeds in an iframe, so the picker cannot join a Wix form; a complete form inside the same embed (posting to Formspree or Basin) does work.
